SUBMISSION VALIDATION ENVIRONMENT

Platform: Windows, using the x86_64-w64-windows-gnu Lean release.
Compiler: Lean 4.24.0, commit 797c613eb9b6d4ec95db23e3e00af9ac6657f24b.
Driver: Python 3.12.10, standard library only; see verification_results.json
for the verification driver's SHA-256.

Validation command:
  python -X utf8 verify.py --fresh --jobs 4 --lake <installed-pinned-lake>

The optional --lake argument selected an existing installed executable. Its
machine-specific path is not needed by this package. Reviewers normally use
the default lake executable supplied by elan on PATH.

The validation reused an existing dependency cache through a temporary
.lake/packages directory junction. All nine dependency Git HEADs match the
pinned lake-manifest.json, and their tracked files were unchanged at inspection.
See dependency_checkouts.json for the administrative check results.

--fresh rebuilds every local proof module; no local compiled proof objects
were copied from the original project. After validation, generated build/cache
directories are excluded from distribution. REPORT.txt and logs/ give the
compiler outcome; this environment description itself is not proof evidence.

This test does not claim an independent clean-machine network installation,
recompilation of all mathlib dependencies, or a Linux/macOS test. The setup
commands use the upstream Lean/mathlib installation workflow and pinned inputs.
