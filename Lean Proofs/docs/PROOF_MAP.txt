HOW TO INSPECT A CLAIM
Open its listed source file at the listed line and read the entire theorem
signature, including all hypotheses. The proof follows ':= by'. Fully
qualified names are unique across modules, even when file and namespace
names differ. In a temporary Lean file in the project, after the build:
  import JunpeiVersionLean
  #check Junpei.RealPrecisionMain.theorem2
  #print axioms Junpei.RealPrecisionMain.theorem2
Then run it with 'lake env lean <your-file>.lean'. The supplied audit files
already provide reproducible versions of these inspections.

A theorem is normally proved using smaller lemmas imported from other files.
The entries below list principal endpoints and useful intermediate results;
they do not repeat every transitive dependency. Keep both Junpei/ and
Draft0/: Draft0 contains required foundations, and its older lemma numbers
are not the current PDF numbering. Use this map rather than those historical
names to locate the manuscript claim. JunpeiVersionLean.lean imports the
complete proof collection.

NOTATION BRIDGE
* Paper arms 1,2,3 correspond to Fin 3 indices 0,1,2 in the policy model.
  The count-path event model retains one-based indexing and proves the bridge.
* Paper odd horizon T=2T'+1 is written T=2q+1.
* Generic Bellman arguments use remaining draws, rather than absolute round.
  EBI(k) compares k remaining draws after a skipped/forced current action;
  inspect each signature rather than substituting paper t for Lean k.
* Theorem 1 uses FiniteHorizon.Policy A N: N Borel draw rules and one
  terminal rule, defined only on strictly positive real precisions.
  Padding unused indices and extending the precision domain preserve
  execution and risk. Reachable initialized counts are positive integers.
* Set N = T - K after initialization. The draw index j = T - t in Fin N
  counts draws remaining after the current action, so calendar order is
  N-1,...,0. Sequential optimality concerns remaining budgets H <= N only;
  N = 0 contains just the terminal recommendation.
* invPower n T denotes (T^n)^(-1). Explicit positive coefficients and uniform
  thresholds implement the paper's Omega bounds.
* The predictive posterior law and the fixed-parameter frequentist reward law
  are distinct measures. Their identities/transfers are proved explicitly.
* Zero regret gives rate +infinity in EReal. The main polynomial bound is on
  odd horizons; the zero limit inferior and ratio consequence concern the
  complete horizon sequence.

SCOPE THAT MUST ACCOMPANY THE BUNDLE
The main algorithm is a posterior-state policy as in Definition 3. No theorem
asserts that every arbitrary history minimizer can be replaced by a state
policy while preserving every history correlation. Proper product-Gaussian
posteriors are the prior class covered by the Bellman optimality proofs.
Auxiliary mock/coupling randomness is realized as independent Gaussian
blocks; no general block-to-one-scalar randomizer compression is supplied.
The labelled adaptive likelihood normalization is not by itself a theorem
about every arbitrary adaptive-history regular conditional distribution.
The actual Gaussian observation/risk bridges are separate named theorems.
Historical claims, cited literature results, and numerical examples are not
silently promoted into formal targets. See ALL_ARGUMENTS_STATUS.txt and
COVERAGE.txt for the inherited full scope record.
